# Beyond Limits — 4 UI variations

Four different organising ideas for the Beyond Limits operations console, built from
reference research across 30 X/Twitter UI posts.

- `v1-command-deck.html` — icon dock + bento grid
- `v2-today.html` — three tabs, one job, a morning briefing
- `v3-spotlight.html` — ⌘K command palette over a live widget field
- `v4-atlas.html` — four plain-English groups + lean mode

All four: liquid glass over an animated wallpaper, navy #183868 / solar #FEDE27 identity,
sample data from the Beyond Limits record.
